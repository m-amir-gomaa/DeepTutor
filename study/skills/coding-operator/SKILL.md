Read this workspace's orientation and library/CODING-ROI.md plus PROJECT-STACK.md.
Begin with the actual freelance stack: JavaScript/TypeScript, React/Next.js,
HTTP/API contracts, SQL/data integrity, authentication/authorization, tests,
debugging, deployment, accessibility and provider limits. Distinguish implemented
implemented project dependencies from provisional technology recommendations.
No simultaneous prerequisite requirement to master Dart, Go, Rust, Python and ML.
Use `official_docs` for current or
version-specific facts and keep retrieved sources linked in the vault. Start
with official MDN, TypeScript, React, Next.js, PostgreSQL, Drizzle and Auth.js docs
for the actual web stack. Use Python, FastAPI, NumPy, pandas, scikit-learn, PyTorch,
Hugging Face, Pydantic and OpenAI documentation for a matching Python/ML/AI unit. Follow the
returned official links to locate a needed section. Say which version was read;
the isolated example runner currently uses Python 3.14. Never call older runtime
output a test of newer-only syntax.

Bridge from existing JS/TS knowledge. Prioritize differences in values/identity,
mutability, comprehensions/iterators, functions, imports, exceptions, types,
environments and async behavior. Do not prescribe another entire language book
or quiz after every syntax paragraph.

For ML, explain array shapes, vectorization, data splitting/leakage, objectives,
metrics, optimization, training versus inference and when fine-tuning is justified.
For agentic systems, explain tool contracts, state, retrieval, evaluation,
idempotency, permissions, failure recovery, latency and cost. For FastAPI, connect
validation, dependency lifetimes, async/blocking work, errors, testing and API
boundaries. Teach what changes the human's decisions and ability to catch errors.
The agent may implement plumbing; do not require manual reproduction of it as a
condition for progressing. Go into implementation depth when the owner asks.

Use complete small `python_example` demonstrations to verify behavior. Its
network-free sandbox is for examples, not package installation or access to
private host files. Do not invoke separately billed models or run training jobs
because a lesson discusses them. Save concise explanations and actual questions
in this Coding vault; do not add them to CLRS interview preparation automatically.
